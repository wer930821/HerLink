# HerLink Android 正式上架版設計規格

日期：2026-10-22

## 目標

重新設計一套獨立的原生 Android 介面，讓 HerLink 成為可提交 Google Play 的正式 App。Web 版維持現有功能與樣式；Android App 採用自己的原生 UI，不再逐頁複製 Web。

## 不變的產品與資料邊界

- 保留匿名即時聊天定位，不恢復交友、按讚或公開探索流程。
- 保留現有 Supabase 資料、RLS、RPC、匿名身分、聊天室與訊息。
- 不重新建立第二套後端，不搬移或重置既有資料。
- Android 只使用 GitHub Actions 建置，不使用 EAS Build。
- 所有使用者介面文字使用繁體中文。

## App 導航

採用原生底部導覽列，分為：

1. 首頁：匿名名稱、開始配對、目前在線與等待人數。
2. 聊天室：所有進行中與歷史聊天室、未讀數。
3. 聯絡人：匿名聯絡人與邀請狀態。
4. 信箱：站長信件與未讀提醒。
5. 設定：帳號綁定、恢復碼、隱私權、條款與支援。

聊天中的首頁導覽列會隱藏，使用原生聊天室返回與動作列。

## 視覺系統

- 深色紫黑背景，橘色作為主要行動色。
- 粉紅／莓紅作為自己的訊息泡泡，深灰紫作為對方泡泡。
- 萬聖節元素作為季節主題：南瓜、蝙蝠、蜘蛛網與微光動畫。
- 所有按鈕、卡片、輸入框採一致圓角、間距、字體與觸控尺寸。
- 不放置無功能的底部裝飾框或重複入口。

## 核心功能

原生 App 必須保留並驗證：

- 匿名登入與匿名名稱更換
- 開始配對、等待配對、下一位
- 即時文字訊息與 Realtime 重連
- 正在輸入提示
- 回覆訊息與回到原訊息
- 圖片選取、預覽、上傳與 5MB 限制
- 訊息回收
- 聊天室恢復碼與永久恢復流程
- 匿名聯絡人邀請與同意
- 封鎖與檢舉
- 高風險內容提示
- 聊天室、聯絡人、信箱未讀提醒
- 推播通知
- Email 綁定、登入、註冊、忘記密碼
- 隱私權、服務條款、支援入口

## 上架要求

- 使用正式 Android applicationId：com.wer93.herlink。
- 產出可提交 Google Play 的 AAB，並保留 APK 作為測試下載。
- 版本號與 versionCode 必須遞增且可覆蓋目前 App。
- 僅要求必要權限：通知、相簿／圖片；不要求不使用的麥克風權限。
- 提供隱私權政策、服務條款、帳號／資料刪除入口。
- 完成 Android 版本、通知、深色模式、不同螢幕尺寸與返回鍵測試。
- 不把金鑰、Firebase 設定、APK 或使用者聊天內容提交到 Git。

## 驗收標準

- 新 App 可從首頁完成配對並進入聊天室。
- 文字、圖片、回覆、回收、下一位、離開、封鎖、檢舉、恢復碼與聯絡人流程可正常完成。
- App 關閉後收到通知，點擊通知可回到正確聊天室。
- 既有匿名身分與聊天室不因更新消失。
- GitHub Actions 成功產出 APK 與 AAB，且可在 Android 實機安裝。
- 建置失敗時不得發布舊版或不完整檔案。

## 實作順序

1. 建立原生設計系統與導航骨架。
2. 重做首頁、配對與聊天室列表。
3. 重做聊天室與訊息互動外觀，接回現有功能。
4. 重做聯絡人、信箱與設定。
5. 補推播、權限、刪除帳號與商店必要頁面。
6. 修正 GitHub Actions，加入正式 AAB 建置。
7. 實機驗證與 Google Play 上架前檢查。
